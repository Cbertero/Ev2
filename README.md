En este repositorio puedes encontrar nuestra evaluación 2, la cual se encuentra configurada en docker, con un contendor, para poder ejecutarla en cualquier lugar
sin tener que tener la conexion a la base de datos, ni al IDE.

Este repositorio cuenta con 2 microservicios, los cuales se realizaron por separado para cuando haya problema en una de ellos, se pueda trabajar en el otro sin problemas
aunque el 2do microservicio debe tener un token de autorización el cual lo entrega el microservicio 1 (producto).
